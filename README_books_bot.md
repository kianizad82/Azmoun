# ربات تلگرام کتاب‌ها (Books Bot)

یک ربات تلگرام ساده که کتاب‌ها را از سایت [books.toscrape.com](https://books.toscrape.com/) استخراج می‌کند، در دیتابیس SQLite ذخیره می‌کند و امکان **لیست** و **جستجو** را فراهم می‌کند.

---

## ویژگی‌ها

- استخراج خودکار عنوان، قیمت و امتیاز کتاب‌ها
- ذخیره در دیتابیس SQLite با SQLAlchemy (جلوگیری از تکراری بودن کتاب‌ها)
- منوی اینلاین کیبورد
- نمایش لیست کتاب‌ها
- جستجوی کتاب بر اساس نام
- نمایش جزئیات هر کتاب (عنوان، قیمت، امتیاز ستاره)

---

## پیش‌نیازها

### ۱. نصب کتابخانه‌ها

```bash
pip install pyTelegramBotAPI requests beautifulsoup4 SQLAlchemy
```

یا با فایل requirements:

```
pyTelegramBotAPI
requests
beautifulsoup4
SQLAlchemy
```

### ۲. ساخت ربات تلگرام

1. به [@BotFather](https://t.me/BotFather) پیام بدهید.
2. دستور `/newbot` را بزنید و نام و یوزرنیم ربات را انتخاب کنید.
3. توکن دریافتی را کپی کنید.

### ۳. قرار دادن توکن

در فایل `books_bot.py` این خط را پیدا کنید:

```python
TOKEN = "???"
```

و توکن واقعی ربات خود را جایگزین کنید:

```python
TOKEN = "123456:ABC-DEF..."
```

### مدل دیتابیس (`Book`)

| ستون   | نوع     | توضیح                     |
|--------|---------|---------------------------|
| id     | Integer | کلید اصلی                 |
| title  | String  | عنوان کتاب (یکتا)         |
| price  | Float   | قیمت                      |
| rating | String  | امتیاز متنی (One تا Five) |

## دستورات و دکمه‌ها

| دستور / دکمه | کار |
|--------------|-----|
| `/start` | نمایش منوی اصلی |
| `/list` | استخراج کتاب‌ها از سایت + نمایش لیست |
| `/search` | درخواست نام کتاب برای جستجو |
| دکمه 📚 List | همان کار `/list` |
| دکمه 🔍 Search | همان کار `/search` |
| کلیک روی نام کتاب | نمایش جزئیات (عنوان، قیمت، امتیاز) |
| دکمه منو | بازگشت به منوی اصلی |

---

## جریان کار

1. کاربر `/start` می‌زند → منوی اصلی نمایش داده می‌شود.
2. با انتخاب **List**:
   - سایت scrape می‌شود.
   - کتاب‌های جدید در دیتابیس ذخیره می‌شوند.
   - لیست تمام کتاب‌های موجود نمایش داده می‌شود.
3. با انتخاب **Search**:
   - ربات از کاربر نام کتاب را می‌پرسد.
   - نتایج مشابه در دیتابیس نمایش داده می‌شود.
4. با کلیک روی هر کتاب، جزئیات آن ارسال می‌شود.

---

## نکات مهم

1. **توکن را در کد هاردکد نکنید**  
   بهتر است از متغیر محیطی استفاده کنید:
   ```python
   import os
   TOKEN = os.getenv("BOT_TOKEN")
   ```

2. **سایت هدف** فقط برای تمرین scraping است (`books.toscrape.com`). برای استفاده واقعی باید قوانین سایت مقصد را رعایت کنید.

3. **امتیاز ستاره** با دیکشنری زیر تبدیل می‌شود:
   ```python
   STARS = {"One": 1, "Two": 2, "Three": 3, "Four": 4, "Five": 5}
   ```

4. در صورت خطای اتصال به اینترنت یا تغییر ساختار سایت، تابع `scrape_books()` ممکن است نیاز به به‌روزرسانی داشته باشد.
